## 部分 1 · 指标定义表

| 指标 | 口径 | 边界处理 | 状态 |
|---|---|---|---|
| `delay_days` | `Delivered to Client Date − Scheduled Delivery Date`（天，date 差值） | 保留负值（提前交付是真实信息，用于分布图）；统计均值时同时报中位数（右偏分布） | 确认 |
| 准时率 `ot_bool` | `delay_days ≤ 0` 即"不晚于计划即准时" | 不设容忍窗口（数据无承诺窗口概念）；提前交付占比单独附注，不混入准时叙事 | 确认 |
| `cycle` 三段 + 总周期 | `c1 = PO − PQ`、`c2 = Scheduled − PO`、`c3 = Delivered − Scheduled`、`total = Delivered − PQ` | 任一端日期缺失/解析失败 → 该段 NaN，该行不参与该段分析但保留其他分析（按需排除，不一刀切）；负 cycle 打 `flag_negative_cycle` 单列核实 | 确认 |
| `unit_freight` | `Freight Cost (USD) ÷ Weight (kg)`，单位 $/kg | 分子为文本（`included`/`invoiced`/`reference`）→ NaN；分母缺失、≤0 或文本引用 → NaN；分子分母均有效才有值；进模型前必须输出分位数 sanity check，`> $10,000/kg` 打 `flag_unit_freight_extreme` 不进回归 | 确认 |
| 异常值标记 | 连续数值列用 `IQR×1.5` 判定离群 → `flag_*_outlier` | 只打标记、不删除；分布图用全量+标记；回归前 winsorize ±1% | 确认 |
| 低频组 | 交叉分析单元格样本 `n < 30` → 归入 `Other` | 仅适用于交叉单元格；Product Group 的 ANTM(22)/MRDT(8)/ACT(16) 是真实小品类，保留但提示小样本 | 修改后确认 |
| 供应商入评门槛 | 同一供应商交付 ≥ 10 单才入评 | 不达标供应商单列"观察名单"，不参与评分 | 确认 |

**统计口径**（贯穿阶段 2–4）：

- 显著性阈值 `α = 0.05`；不显著一律写"无显著差异"
- 组间比较：先 Kruskal-Wallis（延迟右偏、非正态），ANOVA 作对照；显著后做两两比较（Dunn，Tukey HSD 对照）
- 多重比较校正：主用 BH-FDR（q<0.05），Bonferroni 作保守对照；报告注明所用方法
- 每结论固定格式：`检验方法 + 检验统计量 + p/q 值 + 样本量 n`
- 表述纪律：回归/相关仅写"关联/伴随"，禁止"导致/因果"

| 4 | ASN/DN # | str | 发货通知/交货单编号 | 干净 | 保留 |
| 5 | Country | str | 送达国家 | 干净（43 国） | 保留 |
| 6 | Managed By | str | 管理办公室 | 干净（4 值） | 保留 |
| 7 | Fulfill Via | str | 配送方式 | 干净（Direct Drop / From RDC） | 保留 |
| 8 | Vendor INCO Term | str | 贸易术语 | 含 `N/A - From RDC` | 保留，N/A 独立成类 |
| 9 | Shipment Mode | str | 运输方式 | 含 `N/A` | 保留，N/A 独立成类 |
| 10 | PQ First Sent to Client Date | date | 询价发出日 | 格式 `M/D/YY`；`Pre-PQ Process`(2476) + `Date Not Captured`(205) | `pq_flag ∈ {pre_pq, not_captured, date}`；前两类日期置 NaN 并单独计数 |
| 11 | PO Sent to Vendor Date | date | 下单日 | 格式 `M/D/YY`；`N/A - From RDC`(5404，=Fulfill Via From RDC) + `Date Not Captured`(328) | `po_flag ∈ {from_rdc, not_captured, date}`；前两类日期置 NaN 并单独计数 |

| 13 | Delivered to Client Date | date | 实际交货日 | 格式 `D-Mon-YY`；无缺失 | 同上 |
| 14 | Delivery Recorded Date | date | 录入日 | 格式 `D-Mon-YY`；无缺失 | 同上 |
| 15 | Product Group | str | 产品大类 | ARV 8550 / HRDT 1728 / ANTM 22 / MRDT 8 / ACT 16 | 保留（小品类提示小样本） |

| 17 | Vendor | str | 供应商 | 干净（73 家） | 保留 |
| 18 | Item Description | str | 品名描述 | 含品牌/剂型文本 | 保留 |
| 19 | Molecule/Test Type | str | 分子式/检测类型 | 干净（86 种） | 保留 |
| 20 | Brand | str | 品牌 | 48 品牌，Generic 占 7285 行 | 保留；仿制/品牌据此分列 |
| 21 | Dosage | str | 剂量强度 | 55 种 | 保留 |
| 22 | Dosage Form | str | 剂型 | 17 种 | 保留 |
| 23 | Unit of Measure (Per Pack) | int | 每包装单位量 | 纯数字（31 种） | 转数值 |
| 24 | Line Item Quantity | float | 行项目数量 | 全程正数 | 保留 |
| 25 | Line Item Value | float | 行项目总货值 | 17 行 = 0 | 保留，`flag_zero_value` |
| 26 | Pack Price | float | 每盒价格 | 含 0 值 | 保留，0 值标记 |
| 27 | Unit Price | float | 单价 | 含 0 值 | 保留，0 值标记 |
| 28 | Manufacturing Site | str | 生产地点 | 干净（88 处，无文本引用） | 保留 |
| 29 | First Line Designation | str | 是否一线用药 | Yes 7030 / No 3294 | 保留 |
| 30 | Weight (Kilograms) | float | 重量 | 数值 6372 + 文本引用 `See DN/ASN (ID#…)` 覆盖约 3952 行 | 文本→NaN+`flag_weight_reference` |
| 31 | Freight Cost (USD) | float | 运费 | 数值 6198；文本 4126 分三类：`Freight Included in Commodity Cost`(1442)/`Invoiced Separately`(239)/`See ASN…`(2445) | 映射 `freight_flag ∈ {numeric, included, invoiced, reference}`，三类单独计数 |
| 32 | Line Item Insurance (USD) | float | 保险费 | 287 空；54 个 0 | 空→NaN；0 保留（0 保险是真实信息） |
